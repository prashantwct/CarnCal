# assets/

Drop your Wildlife Conservation Trust logo here as:

    wct-logo.png

Recommended: a PNG with a transparent background, roughly 200×80px
(or any size — it's scaled to 34px tall in the header automatically).
An SVG also works if you rename the reference in `index.html` from
`wct-logo.png` to `wct-logo.svg`.

Until this file is added, the header simply omits the logo (the broken
image is hidden automatically, so nothing looks broken in the meantime).
